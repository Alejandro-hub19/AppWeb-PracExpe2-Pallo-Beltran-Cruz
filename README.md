# AppWeb-PracExpe2-Pallo-Beltran-Cruz

Repositorio de entrega para la **Practica Experimental Unidad IV** (Temas 13-16), Grupo PFC. Equipo: **Pallo**, **Beltran**, **Cruz**.

Ver [`LEEME_PRIMERO.md`](LEEME_PRIMERO.md) primero — explica que la mayor parte del codigo de este repo (backend/, frontend/, db/, etc.) es una copia del proyecto real `SGED_APPWEB`, no algo escrito para esta practica especificamente.

## Que hay en este repo

- **`docs/pallo_api_rest_swagger.md`** y **`docs/pallo_soap_vs_rest.md`** — la parte de Pallo (Directrices 3 y 4): demo de API REST + Swagger, y comparativa SOAP vs REST. Esto si es especifico de la practica.
- **`backend/`, `frontend/`, `db/`, `docs/adr/`, `docs/requisitos/`, etc.** — copia del proyecto real SGED (ver `LEEME_PRIMERO.md` y `CONTRIBUTORS.md` para autoria real).
- **`README-SGED-original.md`** — el README original del proyecto SGED, tal como esta en su repositorio real.
